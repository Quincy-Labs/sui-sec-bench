# Responsible use

- Every case is based on a bug that is already public and fixed.
- Exploit tests run only in the local Move test framework. Nothing in this repo
  connects to a live network.
- Do not use this benchmark, its tests, or model outputs against deployed
  contracts. Report new findings through each protocol's disclosure process or
  bug bounty program.
- When a case is based on a third-party protocol, we credit the protocol and the
  auditor in `meta.yaml` and follow the code's license. Protocol teams can ask
  us to change or remove a case by opening an issue.
